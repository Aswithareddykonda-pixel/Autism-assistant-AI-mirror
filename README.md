# 🪞 Autism Assistive AI Mirror

## 📌 Overview

The Autism Assistive AI Mirror is a Python-based assistive technology prototype designed to provide visual routines, communication support, calming guidance, and basic face detection through a smart-mirror-style interface.

The project is intended to support users who may benefit from predictable visual information and alternative communication options.

> **Important:** This project is an assistive prototype and is not intended to diagnose autism, determine a person's emotional state, or replace professional care.

## 🎯 Objectives

* Create a simple AI-assisted smart mirror.
* Provide visual daily routines.
* Provide simple communication options.
* Provide calming and breathing guidance.
* Detect whether a person is visible in front of the mirror.
* Demonstrate how AI and computer vision can be used in assistive technology.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Autism-Assistive-AI-Mirror.git
```

Navigate to the project:

```bash
cd Autism-Assistive-AI-Mirror
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Project

Run:

```bash
python main.py
```

Make sure your computer has a working webcam.

## 🧪 Simulation

When the application starts, the webcam is displayed in the mirror interface.

Example:

```text
========================================
       AUTISM ASSISTIVE AI MIRROR
========================================

        [ CAMERA DISPLAY ]

       Person Detected

Welcome! You are visible in the mirror.

[Daily Routine] [Calm Mode]
[Communication] [Exit]
```

### Daily Routine

The system displays:

```text
DAILY ROUTINE

1. Wake Up
2. Brush Teeth
3. Have Breakfast
4. Go to School / Work
5. Lunch
6. Relax
7. Homework / Activity
8. Dinner
9. Prepare for Sleep
```

### Calm Mode

The system provides simple breathing guidance:

```text
CALM MODE

Take a slow breath.

Breathe in for 4 seconds.
Hold for 4 seconds.
Breathe out for 4 seconds.
```

### Communication

The user can select predefined communication messages:

```text
I am happy
I need help
I need a break
I am tired
I am uncomfortable
```

## 🔐 Privacy Considerations

Because the project uses a camera, privacy should be considered carefully.

Future versions should:

* Process camera data locally where possible.
* Avoid unnecessary recording.
* Avoid storing face images by default.
* Obtain appropriate consent.
* Protect any stored user information.
* Provide a clear camera on/off control.
